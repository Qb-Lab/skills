# Review templates

Three shapes. Fill the one for the mode; delete nothing from the weekly headings, write "none
this week" under a heading that has nothing real. Every claim carries a number with its
count, a file, or an experiment id. No performance data: write "no performance data" where
numbers would go and review execution only.

## Weekly: saved as `<state>/reviews/YYYY-Www.md`

```
# Growth review: <project>, week <YYYY-Www> (<start> to <end>)

Objective this week: <from plans/YYYY-Www.md, or "no plan on file">
Result against it: <metric, number with count, or "no data">

## Completion

| Planned | Status | Note |
| --- | --- | --- |
| <action, content id or experiment id> | done / not done / partly / carried over (nth time) | <reason if known, no judgement> |

Content: <n> planned, <n> published. Experiments: <n> running, <n> due, <n> closed.

## Wins
- <What worked, with its evidence.>

## Losses
- <What did not, with its evidence. Missed work goes in Completion, not here.>

## Learnings
- <Supported by an experiment verdict or an analysis; with confidence low / medium / high.>

## Surprises
- <Something unexpected, good or bad, not yet explained.>

## What we should stop
- <A specific thing and the evidence, or the third carry-over.>

## What we should double down on
- <A specific thing with evidence above the sample minimum; else "repeat <x> to confirm".>

## New hypotheses
- Hypothesis: <statement> : <cheapest way to test it; hand to growth-experiment>

## Next week's objective
<One sentence, one metric, serving the 90-day objective.>

## Top 3 actions
1. <Action, owner, date. Startable today.>
2. <Action, owner, date.>
3. <Action, owner, date.>

## Midweek check
<Kept from the midweek run, if there was one.>
```

## Midweek: a `## Midweek check` section in the week's file

```
## Midweek check (<date>)

1. Experiments running? <EXP id: running since <date> / not started, blocked by <what>>
2. Unusual performance? <content id, numbers against this project's recent median, or "too
   early to read">
3. Winner worth cloning? <content id and what made it work (Inferred) → two or three
   variations, one element changed each; or "no">
4. Anything to stop this week? <what and why, or "no">

Changes to the rest of the week (two at most):
- <change>
```

| What should receive more resources? | | | |

## Learnings confirmed, weakened or overturned this month
