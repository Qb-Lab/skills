# Three-message sequence

Same thread. Each message stands alone for someone who did not read the last one, and each
one is shorter than the one before.

## Message 1 (day 0): the observation

```
Subject: <their product> and <the specific thing>

Hi <first name>,

<The observation: one or two sentences about something specific in their product, hiring,
launch, or reviews. Concrete enough that they know you actually looked.>

<The bridge: why that suggests they may need a complete product or the next version built
fast. One sentence. No adjectives.>

<Proof: one line from proof.md relevant to their sector, honestly labelled, e.g. "We built
a telehealth platform for clinics in two months; happy to show it.">

If it is worth a look, the call is free and you leave with a plan and a fixed quote:
<booking link>

<Owner name>
<Title>, QBLab
```

## Message 2 (day 4): the useful thing

Not "just following up". Give something: a screenshot annotation, a one-line suggestion
about the thing you observed, or a question that shows thought.

```
Subject: Re: <same>

<One sentence: the useful thing, e.g. "Looked at the checkout on mobile again: the address
step loses the cart on back, which is usually a one-day fix.">

<One sentence restating the ask.> <booking link>

<Owner name>
```

## Message 3 (day 10): the close

Polite, final, no guilt.

```
Subject: Re: <same>

<One sentence: closing the loop, leaving the door open.> If the timing is wrong, no
problem; the link works whenever it is right. <booking link>

<Owner name>
```

## LinkedIn variant

Connection note (under 300 characters): the observation, then "Building products for
founders at QBLab. Would be good to connect." No ask in the note. The first message after
acceptance is Message 1 without the subject line and under 80 words.
