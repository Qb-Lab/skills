# Intake questions

Ask in one batch, skipping anything the repository or live product already answered. Offer
the answer you inferred where you have one so the owner only confirms or corrects.

1. **Client.** Who was it built for? May we name them, or should it read as a sector
   ("a clinic group in Dubai")? (Check the overlay's NDA list first.)
2. **Before.** What did they have before QBLab: nothing, a spreadsheet, a no-code tool, an
   agency build, an in-house v1? What was the cost of that: time, money, lost customers?
3. **Trigger.** Why now: a launch date, funding, a customer, something that broke?
4. **Built.** Here is what the repository suggests was built: <list>. What is missing, and
   what should not be listed?
5. **Stack.** The manifests show: <list>. Anything to add or drop?
6. **Timeline.** Commits run from <first date> to <last date>. When was the first version
   live, and is the engagement ongoing?
7. **Outcome.** What changed for the client that can be stated as fact: launched on time,
   first paying users, replaced a tool, a number you are allowed to publish? If there is no
   number, say so; "launched in N weeks and still shipping" is a valid outcome.
8. **Proof.** Is there a client quote we have permission to use (name, role, exact words)?
9. **Screenshot.** Which screen should be the 16:10 image, or is one already in
   `public/projects/`?
